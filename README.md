## 🧭 프로젝트 개요
현대 문명이 멈추고 통신망과 전력망이 단절된 포스트 아포칼립스 상황에서, 주변의 나무·돌·흙 같은 자연물부터 도시에 버려진 빈 깡통·안 쓰는 전기선 등 폐자재까지 활용하여 생명을 유지하기 위한 실전 생존 기술 기록서입니다.

* **완전 오프라인 PWA (Progressive Web App)**: 1회 방문 시 모든 교범 데이터와 스타일이 기기에 사전 캐시되어 비행기 모드 및 통신 두절 시에도 100% 작동
* **인메모리 초고속 검색 & 초성 탐색 엔진**: `Fuse.js` 기반 0ms 반응 속도, 한글 자음 초성 분해 검색(`ㅅㅅ` -> 식수, `ㅂㅇ` -> 바위, `ㅈㅅㄱ` -> 정수기), 실시간 택티컬 하이라이팅 및 35자 스니펫, `Cmd+K` / `/` 단축키 및 방향키 내비게이션 완비
* **7대 글로벌 다국어 지원**: `ko` (한국어), `en` (영어), `ja` (일본어), `es` (스페인어), `de` (독일어), `pt` (포르투갈어), `zh-TW` (중국어 번체) 무새로고침 0.01초 핫스왑
* **6대 생존 공학 체계**: 식수 확보, 불 피우기, 은신처, 식량 채집, 원시 도구, 야전 의약
* **5개 단위 페이징 피드 & 최신순 정렬 토글**: 최신 등록 순서 기본 정렬, 최신순 ↔ 오래된순 1-클릭 토글 및 0.01초 무새로고침 페이징
* **피드 & 상세 일시 정밀 표기**: 피드 카드 헤더 및 상세 히어로 제원 배지에 등록일(`YYYY.MM.DD`) 및 최종 수정 일시(`YYYY.MM.DD HH:mm`) 표기 (소요 독해 시간 문구 완전 배제)
* **브루탈리즘 테크니컬 디자인**: 칠흑의 피치 블랙(`border-radius: 0px`), 1:1 정밀 벡터 인라인 도면, 3D 실물 이미지 에셋 및 16:9 와이드스크린 결과물 프리뷰(Target Outcome)
* **비번호 독립 문서 체계**: 가이드 간 읽는 순서 제약이 없도록 사용자 화면 전반에서 `PR-XX` 일련번호 전면 배제

## 🚀 빠른 시작 (Local Development)

### 1. 의존성 설치
```bash
npm install
```

### 2. 환경 변수 설정
```bash
cp .env.example .env
# .env 파일에 TELEGRAM_BOT_TOKEN 및 GEMINI_API_KEY 설정 (선택 사항)
```

### 3. 정적 빌드 및 컴파일
```bash
npm run build
# 또는
node --experimental-strip-types src/pipeline.ts
```

### 4. 품질 감사 테스트 실행
```bash
npm test
```
*(125개 전수 테스트: 1) 원시 고증 방어, 2) 스키마 규격, 3) LLM 회복력, 4) HTML 무결성 & FOUC 차단, 5) 5개 페이징 & 피드, 6) PWA 오프라인 캐시, 7) 텔레그램 봇 인가 제어, 8) 자동 생성 파이프라인, 9) SEO & AdSense 규격, 10) 벡터 도면 기하학 감사 & 무한루프 차단, 11) 구글 드라이브 문서 동기화 엔진, 12) 기계공학 축 & 유클리드 좌표 정밀 감사, 13) Git/콘텐츠 해시 기반 타임스탬프 동기화 엔진, 14) 테크니컬 라이팅 & 유아어 배제 감수 엔진, 15) 클라이언트 인메모리 검색 엔진 & 초성 탐색 무결성, 16) 4대 포스팅 품질 심사 · 문맥 인라인 하이퍼링킹(`protocol-cross-linker`) · 콘텐츠 보강 감수(`content-enrichment-auditor`) 엔진, 17) Firebase 텔레메트리 런타임 & 보안 규격, 18) 쇼츠 OSMU 패키지)*

### 5. 타임스탬프 & 콘텐츠 해시 물리 동기화
```bash
npm run sync:timestamps
```
*(Git 커밋 이력, 실질 콘텐츠 해시(SHA-256), 파일시스템 변경을 종합하여 마스터 JSON 및 6개국어 번역 파일에 `updatedAt` 및 `contentHash`를 물리적으로 동기화 영속화)*

### 6. 구글 드라이브 클라우드 문서 동기화
```bash
npm run gdrive:sync
```
*(프로젝트 스펙, README, 차기 주제 프롬프트, implementation_plan 전체를 구글 드라이브 공유 폴더에 원클릭 자동 갱신)*

## 🤖 전담 자동화 스킬 (Antigravity Skills)

- **`publish-protocol`**: 신규 생존 가이드 기획부터 초등학생 눈높이 3~6단계 본문 작성, 3D 테크니컬 벡터 SVG 도면 합성, 5대 루브릭 QA 검수, 6대 글로벌 언어 현지화, 정적 빌드, 그리고 **마지막 `sync` 스킬 자동 호출**까지 원스톱으로 완결하는 전담 엔드투엔드 발행 스킬.
- **`publish-protocol-image`**: 제미나이 고화질 실물 이미지(`image-generator` 서브에이전트) 기반 신규 생존 프로토콜 발행 파이프라인(주제 기획 ➔ 원시 고증 & 초등학생 눈높이 쉬운 본문 ➔ 3D 포토리얼리스틱 이미지 생성 ➔ 6대 글로벌 언어 번역 ➔ 정적 빌드/PWA 캐시 ➔ `sync` 스킬 자동 연계 호출)을 원스톱으로 자율 완결하는 전담 이미지 발행 스킬.
- **`sync`**: 코드베이스 변경 사항과 4대 프로젝트 문서 간의 불일치를 전수 검사하고 구글 드라이브 클라우드로 즉시 동기화하는 감사 스킬.
